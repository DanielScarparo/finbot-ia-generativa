# Roteiro do Pitch: FinBot (3 Minutos)

## 1. O Problema (0:00 - 0:45)
"Olá, meu nome é Daniel Alves e eu desenvolvi o FinBot. 
Hoje, o maior desafio das pessoas não é apenas registrar gastos, é entender o que esses gastos significam. Aplicativos tradicionais mostram gráficos frios, mas não conversam com o usuário. Eles não avisam quando um pedido de delivery a mais vai atrasar a viagem dos sonhos. O cliente fica com os dados, mas sem a estratégia."

## 2. A Solução na Prática (0:45 - 2:00)
"Para resolver isso, criei um Agente Financeiro Inteligente usando uma arquitetura RAG. 
Na prática, o usuário acessa uma interface web simples e apenas pergunta: 'Quanto falta para minha meta?' ou 'Onde eu passei do limite este mês?'. O FinBot lê o histórico de transações reais, cruza com o perfil de investidor do cliente e usa inteligência artificial generativa para dar respostas precisas, educadas e totalmente personalizadas, funcionando como um consultor de bolso 24 horas por dia."

## 3. A Inovação e Segurança (2:00 - 3:00)
"A verdadeira inovação deste projeto está na segurança. No setor financeiro, a IA não pode 'alucinar'. Por isso, o motor do FinBot processa os dados localmente usando Python e Pandas, injetando apenas o contexto exato no modelo de linguagem. Ele é blindado: se você pedir uma dica de ação de alto risco ou tentar fazer uma transação fora do escopo, ele recusa a ação. É uma solução que une o poder da IA Generativa com as travas de segurança que um banco exige. Muito obrigado!"
